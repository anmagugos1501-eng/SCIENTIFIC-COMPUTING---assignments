# Results

Generated by `python main.py`.

## tables/
| File | Content |
|---|---|
| `kruskal_wallis.csv` | Test used, statistic and p-value of each feature among the six treatments. |
| `control_vs_methanol.csv` | Kruskal-Wallis between the two control groups. |
| `fdr.csv` | Fisher Discriminant Ratio of each feature. |
| `auc_one_vs_rest.csv` | ROC-AUC of each feature for each treatment against the rest. |
| `auc_control_vs_treated.csv` | ROC-AUC of each feature for control vs. treated sprouts. |
| `threshold_rule.csv` | Metrics of the rule "std_length > threshold → control". |
