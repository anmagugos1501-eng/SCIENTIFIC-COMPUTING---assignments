# Data

## raw/
- `cjs.csv`: original Tree Growth dataset (2,796 sprouts, 35 columns), without any change.
  - Source: Dr. Fernando Camacho (Ontario Hydro Technologies); case study published in the *Canadian Journal of Statistics*, September 1995. Also available in OpenML (dataset `cjs`, id 473).
  - Missing values are marked with `?`.

| Column | Description |
|---|---|
| `N` | Sprout identifier |
| `TR` | Treatment (6 classes): `control`, `methanol_control`, `PP_333_4g/L`, `PP_333_20g/L`, `EL_500_4g/L`, `EL_500_20g/L` |
| `TREE` | Tree identifier (57 trees) |
| `BR` | Branch identifier |
| `TL` | Total length of the sprout (cm) |
| `IN` | Number of internodes |
| `INTERNODE_1` … `INTERNODE_29` | Length of each internode from base to tip (cm) |

## processed/
Generated by `python main.py`:
- `cjs_clean.csv`: clean data (`?` replaced with NaN, internodes as float, categorical columns, `TR_code` from 0 to 5, inconsistent sprout N = 1067 removed). 2,795 sprouts.
- `cjs_features.csv`: clean data plus the seven extracted features.
